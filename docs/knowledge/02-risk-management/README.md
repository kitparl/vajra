# Risk management (Nuksaan se bachna)

**Level:** beginner to intermediate
**Kyun zaroori:** trading me paisa kamane se pehle **paisa bachana** seekhna hota hai. Hamare project ka pehla principle hai: *"Safety before cleverness."*

## Files
| File | Topic |
|---|---|
| `01-risk-basics.md` | Stop loss, position size, drawdown, risk-reward |
| `02-risk-engine-and-kill-switch.md` | Hamara `risk-service`, har order ka veto, kill-switch, fail-closed |
| `03-risk-gate-aur-kill-switch-kaise-chalta-hai.md` | Bank ke limit aur ghar ke main switch ke example se risk gate + kill-switch |

## Ek line me saar
Risk engine ek **sakht chowkidaar** hai. Koi bhi order bina uski ijaazat ke exchange tak nahi jaata, aur wo kabhi "seekhta" nahi, isliye koi ML model use badal nahi sakta.
