# Numbered knowledge topic folders

## Summary
Hinglish topic folders in `docs/knowledge/` now have a two-digit number prefix (`01-trading-basics/` ... `13-frontend-angular/`), so the IDE shows them in reading order and new topics get a fixed place at the end.

## Changes
- Renamed the 13 topic folders using the existing README reading order.
- Updated cross-links between topic notes (`../02-risk-management/` etc.) and the topic table in `docs/knowledge/README.md`.
- Added the naming rule (next free number, never renumbered or reused, append to the table) to `CLAUDE.md` and `docs/knowledge/README.md`.
- Added knowledge doc `0015-topic-folders-numbered.md`.
- Fixed the knowledge path in release doc `1.0.0-repo-folder-structure.md`.

## DB migrations
None.

## Contract changes
None.

## Breaking changes
None. Links or bookmarks to the old folder paths (for example `docs/knowledge/trading-basics/`) need the new prefix.

## Verification
Documentation-only change; checked that every `../` cross-link in the topic notes resolves to an existing file or folder.

## Rollback notes
Remove the `NN-` prefix from the topic folders and revert the link, README and `CLAUDE.md` edits.
